# Changelog

## 0.1.0 — 2026-11-03

Initial educational beta prepared for open-source collaboration.

- Adaptive Copernicus GLO-30 terrain, high-contrast rivers and approximately
  8 km of exterior display context across 20 geocells and 6,820 terrain tiles.
- Regional first-collection and fill-and-spill exploration, with storage estimates
  at the first modelled depression and explicit routing-resolution limits.
- Kaleshwaram project labels, Tummidihatti historical context, seven explanation
  topics, source links and dated CWC / NWIC observation snapshots.
- Desktop, mobile, keyboard and 2D fallback interactions.
- MIT licence for original code and documentation; separate upstream data notices.
- Attributed PNG exports, real screenshot gallery, contribution and security
  policies, issue templates and automated CI.

The atlas does not provide current operating clearance, flood forecasts or
verified district-wise irrigation delivery. See [methods](docs/data-and-method.md).
